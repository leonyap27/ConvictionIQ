# CIQ-9 — Implement Queue Visual States and Status Badges

**Size: L** | **Audience: Management** | **Tag: b**

- **Shipped:** The three decision screens now share a consistent colour system that tells the user what needs attention and what has already been handled, without clicking into individual records. Overdue follow-ups surface as amber rows; recent follow-ups as yellow; actioned records are dimmed; decision outcomes are colour-coded badges.

- **What it unlocks:** Users can scan the Decision Queue at a glance and prioritise action — the visual design is now purpose-built for the CoWork decision workflow rather than a generic list view. The colour-band language (signal strength) is now consistent across all three screens.

- **Two capabilities are partially deferred:** The date-entry widget for scheduling follow-up reviews is a follow-up ticket; the decision badge will appear on-screen once the underlying data record is extended to carry a decision label. Both the colour rules and the component are already built — the remaining work is wiring, not design.
